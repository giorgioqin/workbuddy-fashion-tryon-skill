# WorkBuddy 商品服装换装图策划与质检

把一套服装换装图工作流整理成可复用的 WorkBuddy Skill：先读清衣服，再设计能展示卖点的搭配和画面，准备提示词，按用户授权生成，并对成片做结构与颜色检查。

这个 Skill 是工作方法，不包含生图模型或 API。WorkBuddy 当前会话是否能生成或局部编辑图片，取决于实际启用的能力；能力不可用时，它会提供提示词或修复说明，不会假装已出图。

## 能做什么

- 从衣服参考图提取可确认的颜色、版型、结构、面料与图案信息。
- 对不清楚的关键细节先提问，不靠猜测补全。
- 提炼可由画面证明的卖点，给出搭配、模特、光线和构图建议。
- 按固定结构整理换装图提示词。
- 生成前说明张数、使用的能力和已知成本；默认每件衣服与模特组合只生成一次，不自动重抽。
- 按服装结构、颜色、旧衣残留、遮挡和画面质量检查成片。

## 安装

1. 下载或克隆本仓库。
2. 将仓库目录打包为 ZIP，保留 `workbuddy-fashion-tryon-skill/` 这一层目录；解压后应看到 `workbuddy-fashion-tryon-skill/SKILL.md` 和 `workbuddy-fashion-tryon-skill/references/`。
3. 在 WorkBuddy 打开「专家·技能·连接器」→「添加技能」→「上传技能」，选择该 ZIP。
4. 在本地对话里用 README 中的示例试用。先用虚构描述或获准使用的素材，不要把客户图片提交到公开仓库。

WorkBuddy 的创建入口也可以根据 `SKILL.md` 创建同名技能。补充资料通过 `@references/...` 路径引用。若平台字段或目录校验发生变化，以 WorkBuddy 开放平台当前文档为准。

## 使用示例

- 帮我根据这件外套的照片做一张电商换装图方案，先别生成。
- 给这件针织衫整理搭配和生图提示词。
- 检查这张换装图有没有改掉衣服结构或颜色。

## 设计边界

- 生成需要用户明确提出或确认；额外版本和额外费用需要再次确认。
- 原始图片只读。已有合格成片优先复用，问题先分析能否局部修复。
- 不依赖个人电脑里的私有脚本、密钥、模特库或素材目录。
- 不把客户素材、私人提示词和真实案例提交到公开仓库。
