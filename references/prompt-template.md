# 七段提示词模板

根据具体图片填写。看不清的事实标为未知或先追问，不要补造。

1. **底图与模特**：模特身份、外貌、发型、姿势、场景、背景和光线。用户提供底图时，只写需要保留的特征和允许调整的范围。
2. **服装结构**：逐项描述产品卡确认的颜色、领型、门襟、扣子、口袋、分割线、袖口、下摆、图案和面料纹理。
3. **版型与长度**：描述衣长、袖长、宽松或合身程度，以及下摆相对身体的位置。不要把不同品类名称当成长度描述。
4. **搭配方案**：内搭、下装、腰线、配饰和需要露出的结构。确保搭配不盖住产品卖点。
5. **材质与光线**：说明纹理如何呈现、光泽如何控制、光线从哪里来。保留真实布料细节和自然皮肤质感。
6. **构图与焦点**：衣服在画面中的占比、视线第一落点、人物和背景的视觉权重，以及哪些结构要清楚展示。
7. **保留与排除**：锁定产品颜色、结构、扣子数量、图案、模特身份和姿势；列出需要删除的原衣服、衣架、遮挡物、文字、标志和水印。

## 输出前检查

- 每个结构描述都能在参考图中找到依据。
- 长度、扣子数、图案和颜色没有互相矛盾。
- 每个卖点有具体的画面位置。
- 关键结构没有被内搭、头发、配饰或手挡住。
- 没有把照片无法证明的产品属性写成视觉事实。
