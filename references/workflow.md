# 工作流程

## 1. 素材检查

确认当前任务需要哪些输入：服装正面图或细节图、目标用途、可选模特底图、期望风格，以及是否只要方案或提示词。先判断图是否足以识别衣服。结构被挡、衣服出画、关键细节模糊或颜色严重偏移时，询问最少量的补充信息；不要靠修图或提示词猜出看不见的事实。

## 2. 产品卡

将能确认的内容整理为：

- 品类与版型
- 领型、门襟、口袋、分割线、袖口和下摆
- 可见面料质感、图案和颜色
- 遮挡或无法确认的部分
- 最多三个画面卖点，以及每个卖点对应的画面位置

成分、保暖、透气、产地、尺码等无法从图片验证的属性，只能采用用户提供的资料。

## 3. 搭配与画面

搭配服务于衣服的结构与卖点。优先用简洁内搭和下装，避免配饰、头发、包带或手遮住主结构。领缘、门襟、下摆、袖口等与该款衣服相关的结构点，至少三个应在成片里清楚可读。用光需要显示面料纹理，同时避免强反光把纹理抹掉。

用户提供模特底图时，默认保留人物身份、脸部、体型、姿势和背景。区分换装与重做模特；衣服本身的问题不应自动引发模特重做。

## 4. 生成提示词

按 `prompt-template.md` 写提示词。产品卡是结构事实的唯一依据；与产品卡冲突的旧衣、配饰或颜色要写进排除项。对图中不可见的背面、内衬或成分不作承诺。

## 5. 生成与成本

在生成前确认数量、所用能力和可查到的费用。每件衣服与模特组合默认一张。重复生成、追加版本或切换到可能收费的工具前，需要用户再次明确同意。生成失败时先说明结果和费用是否发生；不要自动重试。

## 6. 验收与交付

按 `quality-checklist.md` 检查。只有用户指定的交付条件都满足时，才称为通过。不能确认的项目标为待人工确认。交付说明应列出文件、尺寸、检查结论和已知成本；不要将中间稿说成终稿。
